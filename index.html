💡 ប្រព័ន្ធរក្សាទុក «តំណ (Link)» ទៅកាន់ឯកសារ (Google Drive, YouTube...) មិនមែនរក្សាទុកឯកសារផ្ទាល់ទេ។ ត្រូវកំណត់ការចែករំលែកឯកសារដែលគ្រូដទៃអាចបើកបាន។ គ្រូគ្រប់គ្នាមើលបាន បន្ថែមបាន តែកែ/លុបបានតែឯកសាររបស់ខ្លួន (Admin កែបានទាំងអស់)។

💡 ចុចលើប្រអប់ណាមួយដើម្បីកែ (ថ្នាក់ · បន្ទប់ · ប្រភេទ)។ កាលវិភាគដែលនាំចូលពី aSc (20/10/2026) ជាការចាប់ផ្ដើម គ្រូម្នាក់ៗផ្ទៀងផ្ទាត់ និងកែបានដោយខ្លួនឯង។ ប្រភេទ «O / OE» = ម៉ោងលើស (OE = ម៉ោងលើសពេលល្ងាច) ហើយចូលទៅក្នុងជួរ «ម៉ោងលើស» ក្នុង Timesheet ដោយស្វ័យប្រវត្តិ។ ម៉ោងមួយ = ១ ម៉ោងបង្រៀន។

💡 ម៉ោងបង្រៀនមូលដ្ឋាន និងម៉ោងលើស ត្រូវបានបំពេញតាមកាលវិភាគរបស់គ្រូនោះ (តាមថ្ងៃក្នុងសប្ដាហ៍) រហូតដល់គ្រូកែដោយខ្លួនឯង។ ជួរ «ផែនការសកម្មភាព» គឺ Workplan ប្រចាំថ្ងៃ។ កាលបរិច្ឆេទជើងក្រោមអាចកំណត់តាមប្រតិទិនខ្មែរ។ ថ្ងៃបុណ្យជាតិដែលមានកាលបរិច្ឆេទថេរត្រូវបានដាក់ជាមុន (ថ្ងៃបុណ្យតាមចន្ទគតិ ដូចភ្ជុំបិណ្ឌ គ្រូកំណត់ដោយខ្លួនឯង)។

📥 នាំចូលពិន្ទុពី Excel

ប្រព័ន្ធផ្គូផ្គងសិស្សតាម ID ប៉ុណ្ណោះ (មិនមែនតាមលំដាប់ ឬឈ្មោះទេ)៖ ត្រូវមានជួរក្បាលតារាង «ID» ឬ «លេខសម្គាល់»។ ជួរដែលគ្មាន ID នឹងត្រូវរំលង។ ប្រព័ន្ធស្គាល់ជួរពិន្ទុតាមក្បាលតារាង៖ October, November, December, January, (February), S_1, March, April, May, June, S_2។ ជួរណាដែលគ្មាននឹងត្រូវបិទដោយស្វ័យប្រវត្តិសម្រាប់ថ្នាក់នោះ។

📋 បិទភ្ជាប់ ID និងឈ្មោះសិស្ស
